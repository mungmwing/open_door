## 구현 계획

1. 공통 효과 정의와 도움말을 확장하고 몬스터/유물/생성 카드의 편집 UI를 만든다.
2. `combat_monsters` 카탈로그와 `items.relic_effects` 컬럼, 검증 및 서버 판정 함수를 수동 SQL로 제공한다. 관전은 별도 SQL로 제공한다. 운영 DB 스키마는 직접 적용하지 않는다.
3. 기존 방 잠금·버전·관리자/소유자 검사·소비 아이템 차감을 유지하며 효과 판정을 진영 기준으로 공통화한다.
4. 전투 시작 시 소환 후보·생성 아이템·장착 유물을 스냅샷으로 고정한다. 등록 몬스터는 방 편성 시 복사한다. 진행 중 카탈로그 변경이 전투에 소급되지 않는다.
5. 실제 RPC를 로컬 인메모리 PostgreSQL에서 검증하고 기존 테스트와 빌드, 화면 확인을 수행한다.

## 적용 규칙

- 기본 수치는 HP·공격·방어이며 시작 파워는 별도 효과 목록이다. 반복 행동을 비워 두면 기존 공격→방어→강타를 사용한다. 직접 설정한 행동은 첫 행동부터 순서대로 반복한다.
- 삽입 카드는 전투의 손패·뽑기·버림 더미 중 선택한다. 손패 10장 초과분은 버림으로 보내고 전투 덱 전체는 200장까지다. 원본 보유 덱은 변경하지 않는다.
- 유물은 카탈로그와 연결되고 보유 수량 1개 이상인 **장착한 유물**을 종류별 1회 적용한다. 기존 인벤토리의 장착 기능을 사용하며 소비품 3칸은 쓰지 않는다. 중복 수량으로 중첩되지 않는다. 전투 시작 시 장착 상태와 최신 효과를 확정한다.
- 소환물은 별도 아군 목록에서 파티 최대 6기까지 유지한다. 소환된 라운드의 플레이어 전원 종료 후부터 순서대로 행동하고 적도 소환물을 공격할 수 있다. 플레이어가 모두 쓰러지면 패배한다. 쓰러진 소환물은 다음 소환 시 정리된다.
- 카드의 턴 종료 효과는 손에 남아 있을 때 사용/소멸 효과와 별개로 발동한다. 이후 에테리얼·유지·버림을 처리한다.
- 가시는 공격을 받으면 방어도로 전부 막아도 반격하며 반격끼리는 재반격하지 않는다. 효과의 `피해`는 공격 판정이며 중독·가시·카드의 `HP 손실`은 공격 판정이 아니다.
- 민첩은 얻는 방어도에 더하고 손상은 그 결과를 25% 줄인다. 금속화는 턴 종료에 고정 방어도를 얻는다. 바리케이드는 턴 시작 방어도 제거를 막는다. 재생은 턴 종료에 회복하고 1 감소한다. 무형은 공격·중독·가시 피해를 1로 제한하며 직접 HP 손실에는 적용되지 않는다. 인공물은 약화·취약·중독·손상 부여를 효과 1건당 1회 막는다.

## SQL 적용

기존 소비 아이템·전용 에너지 SQL까지 적용했다면 다음 두 파일 전체를 순서대로 수동 실행한다.

1. [몬스터·유물·소환 확장 SQL](../supabase/queries/add_combat_monsters_relics.sql)
2. [일반 이용자 관전 SQL](../supabase/queries/add_combat_spectators.sql)

신규 설치 순서: `create_realtime_combat.sql` → `add_card_combat_presets.sql` → `add_combat_consumables_energy.sql` → `add_combat_monsters_relics.sql` → `add_combat_spectators.sql`.

구버전 SQL을 새 확장 뒤에 다시 실행하면 함수가 과거 버전으로 돌아갈 수 있으므로 위 순서를 지킨다. 각각 트랜잭션과 재실행을 지원한다. 앱은 자동 적용하지 않는다. 적용 후 새 전투방을 만들어 사용한다.

## 사용 방법

1. 관리자 메뉴 **몬스터 관리** (`#admin/monsters`)에서 기본 수치, 시작 파워, 반복 행동을 저장한다. 각 `?` 버튼으로 효과 설명을 확인한다.
2. 전투 대기실의 몬스터 목록에서 등록 몬스터를 편성하고 저장한다. 몬스터 행동에 **카드 삽입**을 설정하면 플레이어의 지정 더미에 카드가 들어간다. 방장도 전투 중 카드 삽입 패널을 사용할 수 있다.
3. 카드 편집기의 **아군 소환** 효과에서 미리 등록한 몬스터와 수량을 지정한다. 소환물의 HP·파워·행동도 해당 몬스터 설정을 따른다.
4. 아이템 관리에서 유물의 발동 시점과 효과를 저장하고 캐릭터 인벤토리에서 유물을 장착한다. 새 전투 시작부터 적용된다.
5. 참가자는 대기실과 전장 모두 자기 캐릭터가 **플레이어 1 · 이름 (나)**로 보인다. 표시만 정렬하며 서버 행동 순서와 적의 공격 대상 예고는 유지한다.
6. 일반 로그인 이용자는 전투 목록/초대 화면에서 **관전하기**를 누른다. 관전 중 상태가 갱신되며 새로고침으로 복귀할 수 있다. **관전 나가기**로 목록에 돌아간다. 관전자는 참가 슬롯을 쓰지 않고 카드·아이템·턴 종료·방장 행동을 실행할 수 없다. 관전자는 방마다 최대 100명이다. 새 관전은 대기/진행 중인 방에서 가능하며 기존 관전자는 종료 기록도 다시 볼 수 있다.
